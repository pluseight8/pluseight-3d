# pluseight

Личный сайт с интерактивной 3D-восьмёркой на Three.js. Модель можно вращать мышью, свайпом и клавишами со стрелками. Под сценой находятся переключатель каркаса, управление автовращением и сброс ракурса.

[Открыть сайт](https://pluseight8.github.io/pluseight-3d/)

## Локальный запуск

Запустите сервер в каталоге проекта и откройте [localhost:8000](http://localhost:8000/).

```sh
python3 -m http.server 8000
```

Сборка не требуется. Шрифты и Three.js хранятся в `assets/vendor/` вместе с их лицензиями. При отключённом WebGL отображается статичный ракурс.
